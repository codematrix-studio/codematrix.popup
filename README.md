# CodeMatrix Popup

Модуль **CodeMatrix Popup** для 1С-Битрикс: Управление сайтом (БУС) предназначен для создания и показа всплывающих окон на страницах сайта. Для каждого окна можно выбрать тип, оформить содержимое и настроить условия показа.

## Возможности

- Создание нескольких всплывающих окон и управление ими из административного раздела.
- Выбор типа окна и его шаблона, настройка содержимого и оформления.
- Настройка условий показа, расписания и ограничений повторного отображения.
- Сбор контактных данных через формы.
- Подключение согласий на обработку персональных данных средствами модуля «Согласие пользователя» 1С-Битрикс.
- Отправка данных формы по почте и, при соответствующей настройке, сохранение данных в инфоблоке или списке рассылки.
- Статистика показов, времени просмотра и целевых действий.
- Дополнительные сценарии для купонов, скидок и рулетки при наличии соответствующих модулей и настроек.

## Типы всплывающих окон

В модуле предусмотрены следующие типы:

1. Баннер.
2. Видео.
3. Акция.
4. Социальные сети.
5. Сбор контактов.
6. Поделиться в социальных сетях.
7. Произвольный HTML.
8. Подтверждение возраста.
9. Купон.
10. Рулетка.
11. Скидка.

Доступность отдельных типов зависит от установленных модулей 1С-Битрикс. Например, тип «Купон» добавляется при наличии модуля интернет-магазина `sale`.

## Установка

1. Разместите каталог модуля `codematrix.popup` в каталоге `/bitrix/modules/` вашего проекта либо установите модуль предусмотренным в вашей поставке способом.
2. Откройте административную часть сайта.
3. Перейдите в раздел **Marketplace → Установленные решения** (название пункта может отличаться в зависимости от редакции и версии административного интерфейса).
4. Найдите **CodeMatrix Popup** и выполните установку.
5. После установки откройте раздел **Маркетинг → Всплывающие окна CODEMATRIX**.

При установке модуль создаёт необходимые таблицы и регистрирует обработчик события, который добавляет данные для показа окон в публичной части сайта.

## Первое всплывающее окно

1. Откройте **Маркетинг → Всплывающие окна CODEMATRIX**.
2. Создайте новое окно.
3. Выберите тип окна.
4. Выберите доступный шаблон и настройте его оформление.
5. Заполните содержимое и параметры выбранного типа.
6. Настройте условия показа, расписание и повторное отображение.
7. Сохраните окно и убедитесь, что оно активно.
8. Проверьте показ на публичной странице сайта с учётом заданных условий.

Чтобы окно не показывалось одному посетителю при каждом открытии страницы, настройте условие **«Повторный показ»**.

## Компоненты

Модуль устанавливает компоненты:

- `codematrix:popup.pro` — вывод и обработка всплывающего окна. Основной параметр компонента — `ID_POPUP`, идентификатор настроенного окна.
- `codematrix:popup.pro.timer` — компонент таймера обратного отсчёта.

Компонент `codematrix:popup.pro` использует шаблоны из каталога `install/components/codematrix/popup.pro/templates/`.

## Требования и зависимости

- 1С-Битрикс: Управление сайтом.
- Модуль `main` — базовая инфраструктура 1С-Битрикс.
- Модуль `iblock` — используется для работы с инфоблоками и компонентом.
- Модуль `sale` — требуется для функций, связанных с купонами и корзиной; наличие `sale` влияет на доступность типа «Купон».

Для административного интерфейса модуль поставляет собственную библиотеку jQuery 3.8.0 в `install/js/codematrix.popup/jquery-3.8.0.min.js` и подключает её как зависимость административного скрипта. Не заменяйте этот файл другой версией без отдельной проверки совместимости.

## Важные замечания

- Не переименовывайте коды типов окон, имена компонентов, параметры, CSS-классы и JS-идентификаторы без проверки всех мест их использования.
- Пользовательские шаблоны и цветовые темы могут храниться в базе данных и использоваться отдельно от файлов поставки.
- Перед обновлением файлов на рабочем сайте сделайте резервную копию файлов модуля и базы данных.
