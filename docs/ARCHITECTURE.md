# Архитектура CodeMatrix Popup

## Общая схема

Модуль состоит из административной части, серверной логики, публичного компонента, набора шаблонов и клиентских скриптов.

### Административная часть

Каталог `admin/` содержит страницы управления окнами:

- `codematrix_popup.php` — список окон, создание и редактирование, обработка административных AJAX-команд;
- `codematrix_popup_ajax.php` — отдельный AJAX-обработчик;
- `codematrix_popup_stat.php` — административная страница статистики;
- `menu.php` — пункт меню административной части.

Основной интерфейс использует класс `popupEdit` для чтения и сохранения настроек. Список типов, шаблонов и параметров формируется серверной логикой модуля.

### Серверная логика

- `classes/general/popup.php` — основная логика модуля: типы окон, настройки, условия показа, статистика и подготовка данных для публичной части.
- `classes/general/popup_edit.php` — операции редактирования и сохранения окон, включая пользовательские шаблоны и цветовые темы.
- `lib/tools.php` — вспомогательные методы для работы с группами пользователей, почтовыми шаблонами и свойствами инфоблоков.

### Публичная часть

Основной компонент — `codematrix:popup.pro`:

- принимает параметр `ID_POPUP`;
- получает настройки выбранного окна;
- подготавливает данные для шаблона;
- обрабатывает отправку контактных форм;
- выполняет связанные действия: отправку писем, сохранение в инфоблок и регистрацию согласия, если они включены в настройках.

Компонент таймера расположен в `install/components/codematrix/popup.pro.timer/`.

### Шаблоны и ресурсы

Шаблоны основного компонента находятся в `install/components/codematrix/popup.pro/templates/`. Каждый шаблон может содержать PHP-разметку, CSS, AJAX-обработчик, языковые файлы и цветовые темы.

Ресурсы административного интерфейса и публичной части находятся в `install/themes/` и `install/js/`.

### Клиентские сценарии

- `script.js` — логика административного интерфейса: выбор типа, настройка шаблона, предпросмотр и взаимодействие с формой редактирования.
- `script_public.js` — публичная логика: загрузка окон, проверка условий показа, открытие, закрытие и отправка статистики.
- `jquery-3.8.0.min.js` — поставляемая библиотека jQuery для административного интерфейса.

## Установка и жизненный цикл

Класс установки находится в `install/index.php`. В процессе установки модуль создаёт таблицы настроек, пользовательских цветовых тем и пользовательских шаблонов, регистрирует обработчик публичной части и устанавливает связанные почтовые типы/шаблоны.

Обработчик публичной части подключён к событию `main:OnBeforeEndBufferContent`. При удалении обработчик снимается, а таблицы модуля удаляются.

## Важные контракты

При сопровождении необходимо сохранять согласованность следующих значений:

- идентификатор модуля: `codematrix.popup`;
- компонент: `codematrix:popup.pro`;
- параметр компонента: `ID_POPUP`;
- пространство имён вспомогательного класса: `CodeMatrix\\Popup`;
- коды типов окон и ключи их свойств;
- пути к ресурсам, шаблонам и языковым файлам;
- имена событий и полей, используемые в AJAX-запросах.

Эти значения являются частью внутреннего API модуля и не должны переводиться или переименовываться как обычный текст.
